# DevOps Homelab

A hands-on homelab documenting my transition from **Systems Administration** to **DevOps Engineering** through practical, production-inspired projects.

Rather than following tutorials alone, this repository serves as a living portfolio where I design, build, document, and continuously improve infrastructure using modern DevOps practices and cloud technologies.

---

# Learning Objectives

This homelab focuses on developing practical experience with:

* Linux Administration
* Networking Fundamentals
* Git & GitHub
* Bash & Python Automation
* Infrastructure as Code (Terraform)
* AWS Cloud Services
* CI/CD with GitHub Actions
* Configuration Management (Ansible)
* Docker & Containerization
* Cloud Security
* Monitoring & Observability
* Kubernetes (planned)

# Goals

The objective of this homelab is to develop production-oriented DevOps skills through continuous, hands-on implementation rather than isolated demonstrations.

Every project emphasizes:

* Infrastructure as Code
* Security by Design
* Automation
* Documentation
* Cloud Best Practices
* Operational Excellence

As the homelab evolves, each completed project builds upon previous work to create an increasingly realistic DevOps platform.
